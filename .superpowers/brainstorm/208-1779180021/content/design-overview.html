📦 项目结构

前后端放同一仓库。后端在 backend/，前端在 frontend/。部署时 Vite build → FastAPI 托管静态文件，一个命令启动。

🔌 API 设计

4 组 RESTful 端点：天气代理（后端调 Open-Meteo）、待办 CRUD、笔记 CRUD、倒计时配置。所有数据存 SQLite，不再用 localStorage。

📱 移动端重设计

全屏宽度卡片，大字体(16px+)，触摸友好的按钮(48px+)，卡片间距加大。桌面端仍保持两列网格。
