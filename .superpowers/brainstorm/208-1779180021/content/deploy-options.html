部署到哪？— 上线方案选择

Python 后端 + React 前端，可以部署到以下平台

A

Railway / Render（推荐）

免费额度够用，支持 Python 后端一键部署。前端 Vite build 后放后端静态目录一起部署，一个服务搞定。有自定义域名选项。

B

Vercel（前端）+ Railway（后端）

前端部署到 Vercel（免费、快），后端单独部署。前后端分离，跨域调用。适合后续扩展。

C

国内平台（阿里云/腾讯云）

国内访问速度快，但需要备案域名、付费服务器。如果主要在国内用，体验更好但门槛更高。

D

先不管部署

先把后端和移动端适配搞定，部署的事后面再说。本地能跑起来就行。
